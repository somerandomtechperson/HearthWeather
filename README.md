# HearthWeather
A simple but intuitive weather app for Chrome. You can use it anywhere there is wifi or a stable internet connection. No API keys required.

**Hearth Weather, a cozy, customizable weather app inspired by the feel of Apple Weather and Google Weather.**

Live weather and forecasts
Current conditions, temperature, feels-like temperature, hourly forecasts, 7-day outlook, precipitation chances, UV, humidity, wind, visibility, and sunrise/sunset.




Interactive weather maps
OpenStreetMap street maps, location markers, and RainViewer precipitation radar with a timeline.




Make it your own
Light, dark, or system-adaptive themes; Fahrenheit or Celsius; adjustable wind and precipitation units; movable weather cards; hideable sections; and saved locations.
