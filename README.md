# HearthWeather
A simple but intuitive weather app for Chrome. You can use it anywhere there is wifi or a stable internet connection. No API keys required.

**Hearth Weather, a cozy, customizable weather app inspired by the feel of Apple Weather and Google Weather.**

Hearth Weather is a cozy, customizable weather app inspired by Apple Weather and Google Weather. It provides real-time weather conditions, hourly and 7-day forecasts, precipitation radar, interactive maps, and detailed information like wind, humidity, UV index, and sunrise and sunset times. With adjustable themes, units, saved locations, and movable weather cards, you can personalize the layout to suit your needs. Designed to run directly in your browser, it combines a clean, relaxing interface with useful everyday weather information.
